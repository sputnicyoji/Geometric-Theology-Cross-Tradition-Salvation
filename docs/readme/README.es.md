## Que es GTS?

GTS es un marco topologico que mapea la estructura del "Camino" (Tao/Logos). Propone que la salvacion no es una narrativa religiosa, sino un movimiento geometrico preciso: la convergencia de la conciencia hacia el Eje (R -> 0), donde todos los angulos culturales (theta) se disuelven en el ascenso vertical (Z).

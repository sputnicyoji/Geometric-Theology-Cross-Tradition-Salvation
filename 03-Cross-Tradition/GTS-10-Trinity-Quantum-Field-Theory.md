## 历史：三位一体教义的形成

### 1.1 新约的三一模式

**虽然"Trinity"一词未出现在圣经中，但三一模式无处不在**：

```yaml
大使命（马太福音 28:19）:
  "所以，你们要去，使万民作我的门徒，
  奉父、子、圣灵的名给他们施洗。"

  三个名，但"名"是单数（τὸ ὄνομα）
  → 暗示统一性

保罗祝福（哥林多后书 13:14）:
  "愿主耶稣基督的恩惠、
  神的慈爱、
  圣灵的感动
  常与你们众人同在！"

  三个位格，一个祝福

约翰序言（约翰福音 1:1-14）:
  "太初有道，道与神同在，道就是神。"
  "道成了肉身，住在我们中间。"

  道（Logos）的独特地位

圣灵应许（约翰福音 14-16章）:
  "保惠师，就是父因我的名所要差来的圣灵"

  三者的关系性
```

### 1.2 早期教会的争论

#### Arius异端（约250-336）

```yaml
Arius的主张:

  圣子（Jesus Christ）是被造的（created）
  → "曾经有时，圣子不存在"
  → 圣子次于圣父
  → 圣子不是完全的上帝

神学后果:

  如果基督不是完全的上帝
  → 他不能拯救人类
  → 因为只有上帝能拯救

  这摧毁了救赎的基础

教会的反应:

  尼西亚会议（325）
  → 确立"同质"（homoousios）
  → 圣子与圣父"同一本质"
```

#### 尼西亚信经（325/381）

```yaml
核心表述:

  我信独一上帝，全能的父，
  创造天地的，并造有形无形万物的主。

  我信独一主耶稣基督，
  上帝的独生子，
  在万世以前为父所生，
  出于神而为神，出于光而为光，
  出于真神而为真神，
  受生而非被造，
  与父一体（homoousios tō Patri），
  万物都是借着他造的。

  我信圣灵，赐生命的主，
  从父和子出来，
  与父子同受敬拜，同受尊荣。

关键词汇:

  homoousios（ὁμοούσιος）:
    homo = 同一（same）
    ousia = 本质/实质（substance）
    → "同一本质"

  这一词成为正统与异端的分界线
```

###1.3 为什么如此重要？

```yaml
不只是哲学辩论:

  这关系到:
    - 上帝的本性
    - 基督的身份
    - 救赎的可能性
    - 敬拜的对象

Athanasius的论证:

  只有上帝能拯救人类
  → 如果基督不是完全的上帝
  → 他不能完成救赎

  如果基督只是"最高受造物"
  → 他自己也需要被救
  → 怎能救别人？

实践后果:

  基督徒向基督祈祷
  → 如果基督不是上帝
  → 这就是拜偶像

  基督徒领受圣餐
  → 相信这是基督的身体和血
  → 如果基督不是上帝
  → 这是亵渎

  整个信仰的一致性取决于此
```

## 核心问题：如何既三又一

### 2.1 表面的矛盾

```yaml
一神论的要求:

  "以色列啊，你要听！
  耶和华我们神是独一的主。"
  （申命记 6:4）

  基督教从犹太教继承了严格的一神论
  → 不可妥协

三位格的经验:

  圣父 = 创造者、全能者、天父
  圣子 = 道成肉身、救赎者、中保
  圣灵 = 内住者、安慰者、成圣者

  三者都被敬拜
  三者都被祈求
  三者都在救赎历史中行动

问题:

  如何同时维持:
    - 一神论（monotheism）
    - 三位格的真实性（three persons）

  不陷入:
    - 三神论（tri-theism）
    - 形态论（modalism）
```

### 2.2 常见的异端

#### 异端A：形态论（Modalism）

```yaml
主张（Sabellius, 约220）:

  圣父、圣子、圣灵
  只是同一位上帝的三种"模式"或"面具"

  类比:
    一个人可以是父亲、儿子、丈夫
    但本质上只有一个人

问题:

  1. 圣父不能对圣子说话
  2. 圣子不能向圣父祈祷
  3. 失去了位格间的真实关系

  新约的叙事不成立

教会拒绝:

  三位格不是"角色"或"模式"
  而是真实的、永恒的、不同的位格
```

#### 异端B：三神论（Tri-theism）

```yaml
主张:

  圣父、圣子、圣灵
  是三个分离的神

  类比:
    三个人类个体的联盟

问题:

  1. 违背一神论
  2. 回到多神教
  3. 失去了本质的统一性

教会拒绝:

  三位格共享同一本质
  不是三个独立的上帝
```

#### 异端C：从属论（Subordinationism）

```yaml
主张:

  圣子和圣灵
  次于圣父
  在等级上较低

问题:

  1. 圣子不是完全的上帝
  2. 救赎论崩溃
  3. 敬拜的正当性丧失

教会拒绝（尼西亚）:

  三位格在本质上完全平等
  只有关系上的区别（generation, procession）
  没有等级差异
```

### 2.3 正统的微妙平衡

```yaml
一个本质，三个位格:

  希腊术语:
    Mia ousia, treis hypostaseis
    （μία ούσία, τρεις ύποστάσεις）

  拉丁术语:
    Una substantia, tres personae

关键区分:

  本质/实质（ousia/substantia）:
    - 上帝是什么（what God is）
    - 神性本身
    - 唯一、不可分

  位格/实存（hypostasis/persona）:
    - 谁（who）
    - 存在的方式
    - 三个、真实、永恒

微妙性:

  不是"三个部分"组成一个上帝
  而是"三个位格"共享一个神性

  不是"一个基础"的"三种表现"
  而是"一个本质"的"三种实存"

  语言在此达到极限
  进入奥秘的领域
```

## 教父时期的智慧

### 3.1 Cappadocian Fathers（卡帕多西亚教父，约370-390）

**三位伟大神学家：Basil of Caesarea, Gregory of Nyssa, Gregory of Nazianzus**

#### 3.1.1 ousia与hypostasis的区分

```yaml
Basil的贡献:

  Ousia（本质）:
    - 共同的性质
    - "神性"本身
    - 类比: "人性"

  Hypostasis（位格）:
    - 个别的实存
    - 独特的关系属性
    - 类比: 彼得、保罗、约翰

Gregory of Nyssa的精炼:

  三位格的区别:
    圣父 = 非受生者（agennetos, unbegotten）
    圣子 = 受生者（gennetos, begotten）
    圣灵 = 发出者（ekporeuomenos, proceeding）

  这些不是"时间"的先后
  而是"逻辑"的关系

  永恒的关系
  定义了位格
```

#### 3.1.2 Gregory of Nazianzus的诗意表达

```yaml
"神学讲论"（Theological Orations）:

  "我一想到一（One），就被三（Three）包围
  我一想到三（Three），就被带回一（One）"

  "当我沉思三的时候
  一立即闪耀
  当我凝视一的时候
  三充满我的视野"

  这不是逻辑矛盾
  而是超越逻辑的奥秘

深刻洞见:

  三位一体不是"数学问题"
  1 ≠ 3 in arithmetic
  但在上帝中，一与三共存

  这揭示了受造物逻辑的限度
```

### 3.2 Augustine of Hippo（奥古斯丁，354-430）

#### 3.2.1 心理类比（De Trinitate）

```yaml
Augustine的洞见:

  人是按上帝形像造的
  → 人的心灵应反映三一结构

  三一的痕迹（Vestigia Trinitatis）:

    记忆（Memoria）= 圣父
    理解（Intellectus）= 圣子
    意志（Voluntas）= 圣灵

    三者是一个心灵
    但有不同功能
    互相关联
    不可分离

进一步深化:

  爱者（Lover）= 圣父
  被爱者（Beloved）= 圣子
  爱本身（Love）= 圣灵

  三者构成爱的完整行为
  缺一不可

限度的承认:

  Augustine自己说:
    这些只是"痕迹"（vestigia）
    不是完整的揭示

    人的心灵是受造的、有限的
    上帝的三一是非受造的、无限的

    类比有价值
    但永远不完全
```

#### 3.2.2 关系性的强调

```yaml
Augustine的突破:

  在上帝中
  关系（relatio）就是实在

  圣父不是"先存在"然后"有"圣子
  而是永恒地"是"圣父
  因为永恒地"关联于"圣子

深刻性:

  这挑战了希腊哲学的实体本体论
  → 实体先于关系

  在三一中:
    关系就是存在
    Being = Being-in-relation

  这为后来Zizioulas的位格本体论奠基
```

### 3.3 John of Damascus（约翰·达玛森，约676-749）

#### perichoresis（互渗）理论

```yaml
核心概念（περιχώρησις）:

  peri = 周围、相互
  choresis = 包含、渗透

  不是:
    三个分离的位格"联合"

  而是:
    三个位格"互相内住"
    完全渗透彼此

  圣父在圣子中
  圣子在圣父中
  圣灵在两者中
  三者在彼此中

类比:

  三个完全透明的球体
  完全重叠
  光穿透彼此
  无法分离

意义:

  三位格的统一不是外在的
  而是内在的、本质的

  每个位格包含整个三一
  但仍保持独特性

  这是超越人类经验的奥秘
```

## 中世纪的深化

### 4.1 Thomas Aquinas（托马斯·阿奎那，1225-1274）

#### 4.1.1 纯粹关系（Subsistent Relations）

```yaml
Summa Theologica的核心论证:

  在上帝中:
    关系就是实存
    （relatio = subsistentia）

  三位格的区别:
    不是"属性"的不同
    而是"关系"本身

三种关系:

  Paternitas（父性）:
    - 圣父的关系身份
    - "非受生"+"生出圣子"

  Filiatio（子性）:
    - 圣子的关系身份
    - "被生"+"与圣父共发圣灵"

  Spiratio（发出性）:
    - 圣灵的关系身份
    - "从父子发出"

革命性洞见:

  在受造物中:
    关系是"属性"
    实体先于关系

  在上帝中:
    关系就是实体
    存在=关系

  这是本体论的革命
```

#### 4.1.2 与亚里士多德的对话

```yaml
Aquinas的综合:

  使用亚里士多德的哲学工具:
    - 实体-属性
    - 潜能-实现
    - 四因论

  但超越亚里士多德:
    在上帝中，潜能=0
    在上帝中，本质=存在
    在上帝中，关系=实体

  亚里士多德的工具
  被用来表达
  超越希腊哲学的真理

谦卑的承认（Summa结尾）:

  据说Aquinas在1273年的神秘经验后说:
    "我所写的一切
    在我所见的面前
    都像草芥一样"

  理性神学的最高峰
  仍然承认奥秘的超越性
```

### 4.2 中世纪的光的类比

```yaml
常见的三一类比:

  太阳的三重性:
    光源（Sun）= 圣父
```

## 现代神学的反思

### 5.1 Karl Barth（卡尔·巴特，1886-1968）

#### 启示的三一（Revelatory Trinity）

```yaml
Church Dogmatics的开篇:

  上帝的自我启示本质上是三重的:

    启示者（Revealer）= 圣父
      - 启示的主体
      - 隐藏的上帝

    启示（Revelation）= 圣子
      - 启示的行动
      - 道成肉身的上帝

    启示性（Revealedness）= 圣灵
      - 启示的效果
      - 内住的上帝

深刻性:

  不是"关于上帝的信息"
  而是"上帝自己的临在"

  启示就是三一本身
  不是"三个步骤"
  而是"一个行动的三个维度"

拒绝natural theology:

  人不能通过理性"推导"三一
  只能通过启示接受

  但启示一旦发生
  理性可以深思和阐释
```

### 5.2 Karl Rahner（卡尔·拉纳，1904-1984）

#### Rahner规则

```yaml
核心主张:

  "经世三一就是内在三一
  反之亦然"

  The economic Trinity is the immanent Trinity,
  and vice versa

解释:

  经世三一（Economic Trinity）:
    - 上帝在救赎历史中的显现
    - 我们经验的三一
    - 圣父创造、圣子救赎、圣灵成圣

  内在三一（Immanent Trinity）:
    - 上帝永恒的本性
    - 上帝自身的三一
    - 超越时间和历史

  传统神学倾向于分离两者
  Rahner坚持: 它们是同一实在

意义:

  上帝对我们的显现
  不是"假面"或"表演"

  而是上帝真实的自我给予

  我们在历史中经验的三一
  就是上帝永恒所是的三一

警告:

  不要陷入二元论:
    "上帝自身"（不可知）
    vs
    "上帝为我们"（可知）

  这会导致不可知论
```

### 5.3 Jürgen Moltmann（莫尔特曼，1926-）

#### 受苦的上帝与社会性三一

```yaml
The Crucified God（1974）:

  Moltmann的革命:
    基督在十字架上的受苦

  十字架中的三一:
    圣父"交出"圣子（Romans 8:32）

    圣灵是两者间的痛苦之爱

  三位格共同经历了十字架
  但以不同方式:
    父经历失去儿子的痛
    子经历被弃的痛
    灵经历两者分离的痛

社会性三一（Trinity and the Kingdom, 1981）:

  三位格不是"孤独的个体"
  而是"共融的社群"（Communion）

  上帝的本质 = Perichoresis（互渗）

  这为人类社会提供模型:
    - 不是个人主义
    - 不是集体主义
    - 而是"位格的共融"

  教会应反映三一的共融结构
```

### 5.4 John Zizioulas（约翰·齐齐乌拉斯，1931-2023）

#### 位格本体论（Personhood Ontology）

```yaml
Being as Communion（1985）:

  西方哲学的错误:
    - 个体（individual）是基本单位
    - 关系是次要的、外在的
```

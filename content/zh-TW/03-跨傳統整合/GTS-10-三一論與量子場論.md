## 歷史：三位一體教義的形成

### 1.1 新約的三一模式

**雖然"Trinity"一詞未出現在聖經中，但三一模式無處不在**：

```yaml
大使命（馬太福音 28:19）:
  "所以，你們要去，使萬民作我的門徒，
  奉父、子、聖靈的名給他們施洗。"

  三個名，但"名"是單數（τὸ ὄνομα）
  → 暗示統一性

保羅祝福（哥林多後書 13:14）:
  "願主耶穌基督的恩惠、
  神的慈愛、
  聖靈的感動
  常與你們眾人同在！"

  三個位格，一個祝福

約翰序言（約翰福音 1:1-14）:
  "太初有道，道與神同在，道就是神。"
  "道成了肉身，住在我們中間。"

  道（Logos）的獨特地位

聖靈應許（約翰福音 14-16章）:
  "保惠師，就是父因我的名所要差來的聖靈"

  三者的關係性
```

### 1.2 早期教會的爭論

#### Arius異端（約250-336）

```yaml
Arius的主張:

  聖子（Jesus Christ）是被造的（created）
  → "曾經有時，聖子不存在"
  → 聖子次於聖父
  → 聖子不是完全的上帝

神學後果:

  如果基督不是完全的上帝
  → 他不能拯救人類
  → 因為只有上帝能拯救

  這摧毀了救贖的基礎

教會的反應:

  尼西亞會議（325）
  → 確立"同質"（homoousios）
  → 聖子與聖父"同一本質"
```

#### 尼西亞信經（325/381）

```yaml
核心表述:

  我信獨一上帝，全能的父，
  創造天地的，並造有形無形萬物的主。

  我信獨一主耶穌基督，
  上帝的獨生子，
  在萬世以前為父所生，
  出於神而為神，出於光而為光，
  出於真神而為真神，
  受生而非被造，
  與父一體（homoousios tō Patri），
  萬物都是藉著他造的。

  我信聖靈，賜生命的主，
  從父和子出來，
  與父子同受敬拜，同受尊榮。

關鍵詞彙:

  homoousios（ὁμοούσιος）:
    homo = 同一（same）
    ousia = 本質/實質（substance）
    → "同一本質"

  這一詞成為正統與異端的分界線
```

###1.3 為什麼如此重要？

```yaml
不只是哲學辯論:

  這關係到:
    - 上帝的本性
    - 基督的身份
    - 救贖的可能性
    - 敬拜的對象

Athanasius的論證:

  只有上帝能拯救人類
  → 如果基督不是完全的上帝
  → 他不能完成救贖

  如果基督只是"最高受造物"
  → 他自己也需要被救
  → 怎能救別人？

實踐後果:

  基督徒向基督祈禱
  → 如果基督不是上帝
  → 這就是拜偶像

  基督徒領受聖餐
  → 相信這是基督的身體和血
  → 如果基督不是上帝
  → 這是褻瀆

  整個信仰的一致性取決於此
```

## 核心問題：如何既三又一

### 2.1 表面的矛盾

```yaml
一神論的要求:

  "以色列啊，你要聽！
  耶和華我們神是獨一的主。"
  （申命記 6:4）

  基督教從猶太教繼承了嚴格的一神論
  → 不可妥協

三位格的經驗:

  聖父 = 創造者、全能者、天父
  聖子 = 道成肉身、救贖者、中保
  聖靈 = 內住者、安慰者、成聖者

  三者都被敬拜
  三者都被祈求
  三者都在救贖歷史中行動

問題:

  如何同時維持:
    - 一神論（monotheism）
    - 三位格的真實性（three persons）

  不陷入:
    - 三神論（tri-theism）
    - 形態論（modalism）
```

### 2.2 常見的異端

#### 異端A：形態論（Modalism）

```yaml
主張（Sabellius, 約220）:

  聖父、聖子、聖靈
  只是同一位上帝的三種"模式"或"面具"

  類比:
    一個人可以是父親、兒子、丈夫
    但本質上只有一個人

問題:

  1. 聖父不能對聖子說話
  2. 聖子不能向聖父祈禱
  3. 失去了位格間的真實關係

  新約的敘事不成立

教會拒絕:

  三位格不是"角色"或"模式"
  而是真實的、永恆的、不同的位格
```

#### 異端B：三神論（Tri-theism）

```yaml
主張:

  聖父、聖子、聖靈
  是三個分離的神

  類比:
    三個人類個體的聯盟

問題:

  1. 違背一神論
  2. 回到多神教
  3. 失去了本質的統一性

教會拒絕:

  三位格共享同一本質
  不是三個獨立的上帝
```

#### 異端C：從屬論（Subordinationism）

```yaml
主張:

  聖子和聖靈
  次於聖父
  在等級上較低

問題:

  1. 聖子不是完全的上帝
  2. 救贖論崩潰
  3. 敬拜的正當性喪失

教會拒絕（尼西亞）:

  三位格在本質上完全平等
  只有關係上的區別（generation, procession）
  沒有等級差異
```

### 2.3 正統的微妙平衡

```yaml
一個本質，三個位格:

  希臘術語:
    Mia ousia, treis hypostaseis
    （μία ούσία, τρεις ύποστάσεις）

  拉丁術語:
    Una substantia, tres personae

關鍵區分:

  本質/實質（ousia/substantia）:
    - 上帝是什麼（what God is）
    - 神性本身
    - 唯一、不可分

  位格/實存（hypostasis/persona）:
    - 誰（who）
    - 存在的方式
    - 三個、真實、永恆

微妙性:

  不是"三個部分"組成一個上帝
  而是"三個位格"共享一個神性

  不是"一個基礎"的"三種表現"
  而是"一個本質"的"三種實存"

  語言在此達到極限
  進入奧秘的領域
```

## 教父時期的智慧

### 3.1 Cappadocian Fathers（卡帕多西亞教父，約370-390）

**三位偉大神學家：Basil of Caesarea, Gregory of Nyssa, Gregory of Nazianzus**

#### 3.1.1 ousia與hypostasis的區分

```yaml
Basil的貢獻:

  Ousia（本質）:
    - 共同的性質
    - "神性"本身
    - 類比: "人性"

  Hypostasis（位格）:
    - 個別的實存
    - 獨特的關係屬性
    - 類比: 彼得、保羅、約翰

Gregory of Nyssa的精煉:

  三位格的區別:
    聖父 = 非受生者（agennetos, unbegotten）
    聖子 = 受生者（gennetos, begotten）
    聖靈 = 發出者（ekporeuomenos, proceeding）

  這些不是"時間"的先後
  而是"邏輯"的關係

  永恆的關係
  定義了位格
```

#### 3.1.2 Gregory of Nazianzus的詩意表達

```yaml
"神學講論"（Theological Orations）:

  "我一想到一（One），就被三（Three）包圍
  我一想到三（Three），就被帶回一（One）"

  "當我沉思三的時候
  一立即閃耀
  當我凝視一的時候
  三充滿我的視野"

  這不是邏輯矛盾
  而是超越邏輯的奧秘

深刻洞見:

  三位一體不是"數學問題"
  1 ≠ 3 in arithmetic
  但在上帝中，一與三共存

  這揭示了受造物邏輯的限度
```

### 3.2 Augustine of Hippo（奧古斯丁，354-430）

#### 3.2.1 心理類比（De Trinitate）

```yaml
Augustine的洞見:

  人是按上帝形像造的
  → 人的心靈應反映三一結構

  三一的痕跡（Vestigia Trinitatis）:

    記憶（Memoria）= 聖父
    理解（Intellectus）= 聖子
    意志（Voluntas）= 聖靈

    三者是一個心靈
    但有不同功能
    互相關聯
    不可分離

進一步深化:

  愛者（Lover）= 聖父
  被愛者（Beloved）= 聖子
  愛本身（Love）= 聖靈

  三者構成愛的完整行為
  缺一不可

限度的承認:

  Augustine自己說:
    這些只是"痕跡"（vestigia）
    不是完整的揭示

    人的心靈是受造的、有限的
    上帝的三一是非受造的、無限的

    類比有價值
    但永遠不完全
```

#### 3.2.2 關係性的強調

```yaml
Augustine的突破:

  在上帝中
  關係（relatio）就是實在

  聖父不是"先存在"然後"有"聖子
  而是永恆地"是"聖父
  因為永恆地"關聯於"聖子

深刻性:

  這挑戰了希臘哲學的實體本體論
  → 實體先於關係

  在三一中:
    關係就是存在
    Being = Being-in-relation

  這為後來Zizioulas的位格本體論奠基
```

### 3.3 John of Damascus（約翰·達瑪森，約676-749）

#### perichoresis（互滲）理論

```yaml
核心概念（περιχώρησις）:

  peri = 周圍、相互
  choresis = 包含、滲透

  不是:
    三個分離的位格"聯合"

  而是:
    三個位格"互相內住"
    完全滲透彼此

  聖父在聖子中
  聖子在聖父中
  聖靈在兩者中
  三者在彼此中

類比:

  三個完全透明的球體
  完全重疊
  光穿透彼此
  無法分離

意義:

  三位格的統一不是外在的
  而是內在的、本質的

  每個位格包含整個三一
  但仍保持獨特性

  這是超越人類經驗的奧秘
```

## 中世紀的深化

### 4.1 Thomas Aquinas（托馬斯·阿奎那，1225-1274）

#### 4.1.1 純粹關係（Subsistent Relations）

```yaml
Summa Theologica的核心論證:

  在上帝中:
    關係就是實存
    （relatio = subsistentia）

  三位格的區別:
    不是"屬性"的不同
    而是"關係"本身

三種關係:

  Paternitas（父性）:
    - 聖父的關係身份
    - "非受生"+"生出聖子"

  Filiatio（子性）:
    - 聖子的關係身份
    - "被生"+"與聖父共發聖靈"

  Spiratio（發出性）:
    - 聖靈的關係身份
    - "從父子發出"

革命性洞見:

  在受造物中:
    關係是"屬性"
    實體先於關係

  在上帝中:
    關係就是實體
    存在=關係

  這是本體論的革命
```

#### 4.1.2 與亞里士多德的對話

```yaml
Aquinas的綜合:

  使用亞里士多德的哲學工具:
    - 實體-屬性
    - 潛能-實現
    - 四因論

  但超越亞里士多德:
    在上帝中，潛能=0
    在上帝中，本質=存在
    在上帝中，關係=實體

  亞里士多德的工具
  被用來表達
  超越希臘哲學的真理

謙卑的承認（Summa結尾）:

  據說Aquinas在1273年的神秘經驗後說:
    "我所寫的一切
    在我所見的面前
    都像草芥一樣"

  理性神學的最高峰
  仍然承認奧秘的超越性
```

### 4.2 中世紀的光的類比

```yaml
常見的三一類比:

  太陽的三重性:
    光源（Sun）= 聖父
    光線（Ray）= 聖子
    光照（Illumination）= 聖靈

  優點:
    - 三者同時存在
    - 光源生出光線
    - 光線和光源發出光照
    - 一個光，三種aspect

  限度:
    - 光線可以被阻擋
    - 光源和光線可以分離
    - 這只是受造物類比

  Bonaventure的精緻化:
    光的diffusivum sui（自我擴散性）
    → 聖父必然生出聖子（永恆的自我給予）
```

## 現代神學的反思

### 5.1 Karl Barth（卡爾·巴特，1886-1968）

#### 啟示的三一（Revelatory Trinity）

```yaml
Church Dogmatics的開篇:

  上帝的自我啟示本質上是三重的:

    啟示者（Revealer）= 聖父
      - 啟示的主體
      - 隱藏的上帝

    啟示（Revelation）= 聖子
      - 啟示的行動
      - 道成肉身的上帝

    啟示性（Revealedness）= 聖靈
      - 啟示的效果
      - 內住的上帝

深刻性:

  不是"關於上帝的信息"
  而是"上帝自己的臨在"

  啟示就是三一本身
  不是"三個步驟"
  而是"一個行動的三個維度"

拒絕natural theology:

  人不能通過理性"推導"三一
  只能通過啟示接受

  但啟示一旦發生
  理性可以深思和闡釋
```

### 5.2 Karl Rahner（卡爾·拉納，1904-1984）

#### Rahner規則

```yaml
核心主張:

  "經世三一就是內在三一
  反之亦然"

  The economic Trinity is the immanent Trinity,
  and vice versa

解釋:

  經世三一（Economic Trinity）:
    - 上帝在救贖歷史中的顯現
    - 我們經驗的三一
    - 聖父創造、聖子救贖、聖靈成聖

  內在三一（Immanent Trinity）:
    - 上帝永恆的本性
    - 上帝自身的三一
    - 超越時間和歷史

  傳統神學傾向於分離兩者
  Rahner堅持: 它們是同一實在

意義:

  上帝對我們的顯現
  不是"假面"或"表演"

  而是上帝真實的自我給予

  我們在歷史中經驗的三一
  就是上帝永恆所是的三一

警告:

  不要陷入二元論:
    "上帝自身"（不可知）
    vs
    "上帝為我們"（可知）

  這會導致不可知論
```

### 5.3 Jürgen Moltmann（莫爾特曼，1926-）

#### 受苦的上帝與社會性三一

```yaml
The Crucified God（1974）:

  傳統神學:
    上帝不可受苦（impassible）
    → 完全超越，不受影響

  Moltmann的革命:
    基督在十字架上的受苦
    進入了三一本身

  十字架中的三一:
    聖父"交出"聖子（Romans 8:32）
    聖子"被棄"（Mark 15:34："我的神，為什麼離棄我？"）
    聖靈是兩者間的痛苦之愛

  三位格共同經歷了十字架
```

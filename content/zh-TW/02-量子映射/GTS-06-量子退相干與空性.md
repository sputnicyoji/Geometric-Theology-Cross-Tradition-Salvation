## Part I: 核心問題——為何世界顯得經典?

### 1.1 量子-經典鴻溝

**量子世界的怪異性質**:

```yaml
疊加(Superposition):
  粒子可以同時處於多個狀態
  |ψ⟩ = α|0⟩ + β|1⟩

  薛定諤的貓:
  同時死和活

糾纏(Entanglement):
  兩個粒子「神秘」關聯
  測量一個,瞬時影響另一個
  即使相隔光年

非局域性(Non-locality):
  空間分離不意味獨立
  "spooky action at a distance"(Einstein)

不確定性(Uncertainty):
  位置和動量不能同時精確
  ΔxΔp ≥ ℏ/2
```

**宏觀世界的經典性質**:

```yaml
確定性:
  桌子在那裡,不在疊加態
  不會「同時在這裡和那裡」

局域性:
  這裡的事件不瞬時影響那裡
  因果需要傳播時間

可預測性:
  給定初始條件
  可以精確預測未來

分離性:
  物體各自獨立
  「這個蘋果」和「那個蘋果」是分離的
```

**中心困惑**:

```
量子力學是基礎理論
宏觀世界由量子微觀構成

但為何宏觀世界不顯示量子性質?

為何我們看不到:
- 宏觀疊加(桌子同時在兩處)
- 宏觀糾纏(這個桌子與那個桌子瞬時關聯)
- 宏觀不確定性(桌子位置模糊)

這被稱為「測量問題」或「量子-經典過渡」
```

## Part II: 量子退相干的物理學

### 2.1 數學形式化

**純態 vs 混態**:

```yaml
純態(Pure State):
  |ψ⟩ = α|0⟩ + β|1⟩
  密度矩陣: ρ = |ψ⟩⟨ψ|

  ρ = ( |α|²      αβ*  )
      ( α*β       |β|²  )

  非對角項 αβ* ≠ 0
  → 量子干涉

  Tr(ρ²) = 1
  → 純態標誌

混態(Mixed State):
  ρ = p₁|ψ₁⟩⟨ψ₁| + p₂|ψ₂⟩⟨ψ₂|
  經典概率混合

  非對角項 = 0
  → 無干涉

  Tr(ρ²) < 1
  → 混態標誌
```

**退相干的精確定義**:

```yaml
給定:
  系統S + 環境E
  初始: |ψ_S⟩ ⊗ |E₀⟩(未糾纏)

演化(通過相互作用哈密頓量H_int):
  U(t)|ψ_S⟩|E₀⟩ = Σᵢ cᵢ(t)|sᵢ⟩|Eᵢ⟩

  |sᵢ⟩: 系統的正交態(「指針態」)
  |Eᵢ⟩: 對應的環境態
  cᵢ(t): 振幅

約化密度矩陣:
  ρ_S(t) = Tr_E(|ψ⟩⟨ψ|)
        = Σᵢ |cᵢ|²|sᵢ⟩⟨sᵢ|
        + Σᵢ≠ⱼ cᵢcⱼ*⟨Eᵢ|Eⱼ⟩|sᵢ⟩⟨sⱼ|

退相干:
  ⟨Eᵢ|Eⱼ⟩ → 0 (環境態變正交)

  → ρ_S ≈ Σᵢ |cᵢ|²|sᵢ⟩⟨sᵢ|

  只剩對角項
  = 經典概率分佈
```

  與環境糾纏慢
  → 退相干慢
  → 更「經典」

  動量本徵態:

  極快糾纏

## Part III: 佛教空性教義核心

### 3.1 空性(Śūnyatā)不是虛無

**常見誤解**:

```yaml
錯誤理解1:
  空性 = 虛無(Nihilism)
  一切不存在

反駁(龍樹《中論》):
  「空亦復空」
  空性本身也是空的
  → 不是斷滅見

錯誤理解2:
  空性 = 否定現象
  世界是幻覺

反駁:
  「色即是空,空即是色」(《心經》)
  現象與空性不二
  → 不是否定世界
```

**正確理解:無自性**

```yaml
梵文: Svabhāva-śūnyatā
  Svabhāva = 自性(inherent existence)
  Śūnyatā = 空(emptiness)

核心主張:
  萬物無自性
  無獨立存在
  無固有本質

三個層次:

1. 無常(Anicca):
   一切都在變化
   沒有永恆不變的「實體」

2. 無我(Anātman):
   沒有獨立的「自我」
   五蘊(色受想行識)都是緣起

3. 緣起(Pratītyasamutpāda):
   一切因緣和合而生
   無一物獨立存在
```

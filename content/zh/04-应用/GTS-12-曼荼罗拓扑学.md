### 1.1 什么是曼荼罗？(What is a Mandala?)

梵文词汇 *maṇḍala* (मण्डल) 意为"圆"(circle) 或"完整"(completion)。在其最基本的形式中，曼荼罗是一个**围绕中心点组织的几何图案，以径向对称 (Radial Symmetry) 和同心层 (Concentric Layers) 为特征**。

但这个简单的定义隐藏了非凡的深度。曼荼罗独立出现在相隔巨大距离和数千年的人类文明中：

**藏传佛教 (Tibetan Buddhism)**：在冥想中观想的精致宫殿结构，以几何排列描绘佛部 (Buddha Families)。沙曼荼罗需要数周构建，然后在几分钟内被扫除。

**荣格心理学 (Jungian Psychology)**：在心理危机期间从患者那里自发涌现的绘画。荣格在他的"与无意识的对抗" (Confrontation with the Unconscious, 1913-1917) 期间记录了自己的系列作品，注意到它们每天反映他的心理状态。

**印度教密宗 (Hindu Tantra)**：用于冥想的曼陀罗 (Yantras)（特别是吉祥轮 Sri Yantra），由围绕中心明点 (Bindu) 的交错三角形组成递归图案。

**基督教神秘主义 (Christian Mysticism)**：哥特式大教堂中的玫瑰窗 (Rose Windows)、宾根的希尔德加德 (Hildegard von Bingen) 的神秘视觉、彩饰手稿中的几何图案。

**伊斯兰艺术 (Islamic Art)**：清真寺中精致的几何瓷砖工艺，基于对称和比例的数学原理。

**原住民传统 (Indigenous Traditions)**：纳瓦霍沙画 (Navajo Sand Paintings)、阿兹特克历法石 (Aztec Calendar Stones)、澳大利亚原住民艺术，所有这些都展现曼荼罗结构。

## 第二部分：曼荼罗的拓扑学 (Part II: Topology of the Mandala)

### 2.1 曼荼罗作为俯视投影 (Mandala as Top-Down Projection)

**核心几何洞见**：曼荼罗是当你从**正上方**、沿着中心轴向下看螺旋锥时所看到的。

回顾GTS-02中的螺旋锥：
```
螺旋锥方程 (Spiral Cone Equation):
  r(t) = r₀ · e^(-kt)
  θ(t) = ωt
  h(t) = v_h · t

其中 (Where):
  r = 半径 (radius)（距离轴心的距离）
  θ = 角度 (angle)（圆上的位置）
  h = 高度 (height)（灵性层次）
```

当从上方观看（投影到h=常数平面）时，你看到：
- **同心圆 (Concentric Circles)**（不同的r值）
- **径向线 (Radial Lines)**（不同的θ值）
- **中心点 (Center Point)**（r=0，轴心）

这正是曼荼罗结构！

**几何投影 (Geometric Projection)**：
```
投影映射 π: ℝ³ → ℝ²
π(r, θ, h) = (r, θ)
```

高度维度h被"压缩"到符号内容s(r,θ)中——不同的灵性层次在同一(r,θ)位置看到不同的本尊/图案。

**为什么是圆形？(Why Circular?)**

圆形不是任意的，而是拓扑上必需的。螺旋锥围绕其轴具有旋转对称性 (Rotational Symmetry)。任何旋转对称的三维物体投影到垂直于轴的二维平面上都会产生圆形对称。

这解释了为什么圆在灵性象征中是普遍的：
- **衔尾蛇 (Uroboros)**（咬尾蛇）：圆形完成
- **法轮 (Wheel of Dharma)**：轮回的循环性质
- **光环 (Halo)**：从中心自性 (Self) 辐射的光芒
- **地平线 (Horizon)**：已知世界的边界

所有这些都是超越的垂直轴投影到二维空间中。

### 2.2 数学形式化：纤维丛 (Mathematical Formalization: Fiber Bundles)

**定义 (Definition)**：
```
曼荼罗 M = {(r, θ, s) | 0 ≤ r ≤ R, 0 ≤ θ < 2π, s ∈ S}

其中 (Where):
  基空间 B = {(r,θ)} - 几何布局
  总空间 M - 带符号的完整曼荼罗
  纤维 F = S - 每个点的符号/原型内容
  投影 π: M → B, π(r,θ,s) = (r,θ)
```

**这意味着什么 (What This Means)**：

曼荼罗平面中的每个点(r,θ)都附加了一个"纤维"S——可以出现在那里的可能符号内容（本尊、颜色、咒语等）集合。

不同的观察者在不同的灵性高度h看到不同的纤维：
```
s = s(h)
```

**例子——时轮金刚曼荼罗 (Kalachakra Mandala)**：

- 在r=0（中央宝座）：父母尊双运的时轮金刚本尊

**几何是恒定的**（同心圆，四门）。**内容是h依赖的**（你观想什么取决于你的证悟层次）。

这就是为什么真实的曼荼罗实践需要传承传授 (Lineage Transmission)——你需要知道你当前层次的正确映射s(h)。

- 保持 = 酉演化（维持相干性）
- 消解 = 下次"测量"（坍缩回无形）

保持阶段是维持**退相干状态 (decohered state)**（GTS-06）：
- 色（rūpa，形式）暂时稳定
- 但底层的空性（śūnyatā）仍然存在
- 高级修行者同时看到两者："色即是空，空即是色"

#### 4.1.3 消解：回归隐卷序 (Dissolution: Return to Implicate)

**物理沙坛曼荼罗消解 (Physical Sand Mandala Dissolution)**：

经过数天/数周后，曼荼罗被仪式性地摧毁：
- 扫除仪式（通常公开）
- 沙子从外向内扫（构建的逆过程）
- 混合到容器中
- 通常分散到河流中（回归自然）
- 整个过程需要几分钟

**心理影响 (Psychological Impact)**：

目睹这一过程创造：
- **震惊 (Shock)**：美丽的东西被摧毁
- **悲伤 (Grief)**：执着被揭示
- **惊奇 (Wonder)**：接受无常
- **解脱 (Liberation)**：贪执被释放

**无常教义 (Teaching of Impermanence, Anicca)**：

表面含义：所有有为法都是无常的。

但更深层含义（GTS-05整合）：

曼荼罗不是被摧毁——它被**重新卷入隐卷序 (RE-ENFOLDED into the implicate order)**！

沙子回归未分化状态，但信息（图案、加持、证悟）回归法身/隐卷域。

在玻姆的墨滴实验中：
- 分散的墨水看起来"被摧毁"
- 但反向旋转证明它被卷入，而非摧毁
- 图案可以恢复

同样：
- 消解的曼荼罗看起来消失了
- 但图案保留在：
  - 见证者的记忆中
  - 赋予的加持中
  - 隐卷序中的几何结构
- 随时可以重建

**心智曼荼罗消解 (Mental Mandala Dissolution)**：

保持观想后，修行者消解它：
```
观想脚本 (Visualization Script):
1. 外墙消解为光
2. 门、护法向内消解
3. 同心层逐一消解
4. 中心本尊消解为光
5. 光消解为空间
6. 空间消解为空性（śūnyatā）
7. 安住于空性（无形觉知）
```

这是**系统性维度约简 (systematic dimensional reduction)**：
- 2D曼荼罗 → 1D光线 → 0D点 → -1D空性（？）

空性的"负维度"代表超越维度本身——所有空间维度下的隐卷序。

**相变 (Phase Transition)**：

消解是**相变 (phase transition)** ——状态的不连续变化：

固态（形式）→ 液态（光）→ 气态（空间）→ 等离子态（空性）

每个相有不同性质：
- 固态 (Solid)：保持形状，抵抗变化
- 液态 (Liquid)：流动，适应
- 气态 (Gas)：扩张，充满容器
- 等离子态 (Plasma)：纯能量，无结构

高级修行者可以随意在相之间转换——这是大圆满（Dzogchen）中的"虹身 (rainbow body, jalus)"教法。

### 4.2 渐进道路 (The Graduated Path)

曼荼罗实践不是单一的，而是有与修行者能力匹配的渐进阶段。

#### 4.2.1 前行法 (Preliminary Practices, Ngöndro)

**在曼荼罗实践开始之前**，修行者完成基础训练：

- 曼荼罗供养（100,000+）：布施训练

**前行法的目的 (Purpose of Preliminaries)**：

心智必须准备好接受高级修行。没有基础：
- 观想缺乏稳定性
- 理解缺乏深度
- 体验缺乏整合

把它想象成高等数学前的先修课程——你需要微积分才能学习拓扑学。

**螺旋锥映射 (Spiral Cone Mapping)**：

前行法建立：

- 朝向轴心的意图（速度向量）
- 障碍（反作用力）被识别和减少

没有这些，曼荼罗实践就像没有坐标导航——你在移动但不知道在哪里。

#### 4.2.2 生起次第 (Generation Stage, Kyerim)

**Kyerim**（藏文：བསྐྱེད་རིམ）= "生起次第 (Generation Stage)"或"发展阶段 (Development Stage)"

**核心实践 (Core Practice)**：
- 观想自己是曼荼罗中心的本尊
- 详细观想宫殿
- 维持稳定观想
- 包括持咒
- 保持延长时间（30分钟到数小时）

**三种观想类型 (Three Types of Visualization)**：

1. **粗糙 (Coarse, བྱེ་བརག)**：专注于一般形式、颜色
   - 适合初学者
   - 外部曼荼罗（你从外面观察）
   - r > 0（你仍在距中心有距离处）

2. **微细 (Subtle, རྣམ་པར་དག་པ)**：精确细节，每个元素
   - 适合中级修行者
   - 开始认同中心本尊
   - r减少（向内移动）

3. **极微细 (Very Subtle, ཤིན་ཏུ་རྣམ་པར་དག་པ)**：坍缩到本质结构
   - 适合高级修行者
   - 完全认同本尊
   - r → 0（你就是中心）

**几何进程 (Geometric Progression)**：

生起次第训练：
- **构建 (Construction)**：从隐卷序构建显展序（创造技能）
- **维持 (Maintenance)**：保持形式稳定（专注技能）
- **认同 (Identification)**：认识本尊为自性（认知技能）

用螺旋锥术语：
- 你在学习有意识地导航r空间
- 每次座修是一次向内螺旋转
- 累积效果：r在数月/数年中减少

#### 4.2.3 圆满次第 (Completion Stage, Dzogrim)

**Dzogrim**（藏文：རྫོགས་རིམ）= "圆满次第 (Completion Stage)"或"完美阶段 (Perfection Stage)"

**核心实践 (Core Practice)**：
- 消解观想的曼荼罗
- 处理微细身（脉、气、明点）
- 直接认识心性
- 无二元觉知

**两个阶段 (Two Phases)**：

1. **有相 (With Form, རྣམ་པ་ཅན)**：
   - 系统性消解曼荼罗
   - 本尊消解为光，光入空间，空间入空性
   - 训练无形状态

2. **无相 (Without Form, རྣམ་པ་མེད)**：
   - 直接安住于空性（śūnyatā）
   - 根本不观想
   - 纯觉知无对象

**为什么叫"圆满"？(Why "Completion"?)**

不是因为修行完成了，而是因为：
- 形式执着被圆满（消解）
- 二元性被圆满（认识为显现）
- 旅程被圆满（到达r=0）

**微细身实践 (Subtle Body Practices)**：

圆满次第包括：
- **拙火 (Tummo, གཏུམ་མོ)**：内热，脉净化
- **颇瓦 (Phowa, འཕོ་བ)**：意识转移
- **梦瑜伽 (Dream Yoga)**：清明梦修行
- **中阴 (Bardo)**：为死亡/转生状态准备

所有这些都处理观想下的**能量基础设施 (ENERGETIC infrastructure)**。

**螺旋锥圆满 (Spiral Cone Completion)**：

当生起次第完善**构建/维持**（显展序）时，
圆满次第完善**消解/认识**（隐卷序）。

一起：
- 生起 = 学习显化（道 → 万物）
- 圆满 = 学习回归（万物 → 道）

精通意味着两者之间的流畅——虹身成就者可以：
- 需要时显现形式（显展）
- 适当时消解为光（隐卷）
- 在任一状态都不失觉知（无二元）

### 4.3 本尊瑜伽：成为中心 (Deity Yoga: Becoming the Center)

**金刚乘核心教法 (Core Vajrayana Teaching)**：你不是在崇拜本尊。你**就是 (ARE)**本尊。

**三阶段认同 (Three Stages of Identification)**：

1. **对生 (In Front, མདུན་བསྐྱེད)**：
   - 观想本尊在你前面
   - 你是观察者，本尊是被观察者
   - 主客二元性维持
   - 初级实践

2. **自生 (Self-Generation, བདག་བསྐྱེད)**：
   - 观想你自己**就是**本尊
   - 你是中心人物
   - 你的身体是宫殿
   - 你的意识是本尊的智慧
   - 高级实践

3. **无二 (Non-Dual, གཉིས་མེད)**：
   - 你和本尊之间没有区别
   - 认识：本尊一直是你的真实本性
   - 曼荼罗是智慧的自发显现
   - 证悟

**为什么这有效？(Why This Works?)**

从GTS-01（通道本体论）角度：

本尊不是外部实体，而是**轴心的人格化表现 (personified representation of the axis)** ——组织中心、自性、流经你的道。

当你观想自己为本尊时：
- 你在练习r=0（成为中心）
- 你周围的曼荼罗是现象世界
- 你在训练成为通道，而非被通道的东西

**心理机制 (Psychological Mechanism, Jung)**：

本尊是**原型 (archetype)** ——集体无意识中的模式。

"成为"本尊意味着：
- 激活你心理中的那个原型模式
- 允许它组织意识
- 整合它的品质（慈悲、智慧、力量等）

这是安全的因为：
- 它被包含在仪式结构中（曼荼罗作为安全空间）
- 它是暂时的（你消解认同）
- 它是受监督的（传承传授确保健康模式）

**没有指导的危险 (Dangers Without Guidance)**：

没有适当训练的本尊瑜伽可能导致：
- **膨胀 (Inflation)**：自我为自己声称本尊的力量
- **解离 (Dissociation)**：失去与日常现实的接触
- **附身 (Possession)**：无意识情结采取本尊形式

这就是为什么传承传授至关重要——上师确保：
- 适当准备（前行法完成）
- 正确理解（本尊是空性，非实质）
- 平衡实践（生起**和**圆满，不只是一个）

**螺旋锥动力学 (Spiral Cone Dynamics)**：

本尊认同是练习**r=0, h→∞**：
- 在曼荼罗中心（r=0）
- 体现最高证悟（h→∞）

这是愿景性的——你练习结果以达成道路：
- 表现得好像已证悟
- 意识逐渐与那个模式对齐
- 最终认识："我一直都是这样"

### 4.4 五佛家族作为基组 (Five Buddha Families as Basis Set)

```
心理状态 (Mental State) = a₁·毗卢遮那 + a₂·阿閦 + a₃·宝生 + a₄·阿弥陀 + a₅·不空成就
```

系数a₁...a₅描述哪些佛族能量处于激活状态。

**几何意义 (Geometric Meaning)**：

五个方向（中心+四方）代表：
- **中心（毗卢遮那）**：轴心本身（r=0）

所有其他位置都是线性组合：
```
θ = 30° 在东（0°）和南（90°）之间
  = 0.67·阿閦 + 0.33·宝生
```

**曼荼罗作为转化地图 (Mandala as Transformation Map)**：

五佛家族提供：
- **诊断 (Diagnosis)**：哪些毒素处于激活状态？
- **道路 (Path)**：应培养哪些智慧？
- **目标 (Goal)**：整合所有五个（毗卢遮那作为统一）

这就是为什么不同修行者使用不同本尊——他们在处理特定的毒-智转化需求。

墙之间：可能的连续渐进接近
门处：需要不连续的阈值跨越

守护者不是外部敌人，而是**你自己抵抗的投射 (projection of your own resistance)**。

#### 4.5.2 同心层：渐进接近 (Concentric Layers: Gradual Approach)

**为什么分层？(Why Layers?)**

直接面对究竟实相会压倒未准备的意识。层次提供：

1. **渐进揭示 (Progressive Disclosure)**：每层比前一层揭示更多
2. **适应 (Acclimatization)**：意识在进入下一层前调整到每一层
3. **测试 (Testing)**：每层测试对下一层的准备
4. **整合 (Integration)**：必须整合每层的洞见

**几何解释 (Geometric Interpretation)**：

每层是一个**等高线 (level set)** ——距中心等距的点：
```
Layer_n = {(r,θ) | r = r_n}
```

冥想通过减少r进行：
```
r₀ (开始) → r₁ → r₂ → r₃ → 0 (中心)
```

每次跨层是灵性进步的一个量子。

**Yab-Yum**（藏文：ཡབ་ཡུམ）= "父-母 (Father-Mother)"

- 结合：无二元整合

**不是字面的性 (Not Literal Sexuality)**：

   - 智慧/慈悲
   - 空性/色
   - 阳性/阴性
   - 阴/阳
   - 隐卷/显展

2. **无二元觉知 (Non-Dual Awareness)**：
   - 主体和客体合一
   - 知者和所知不可分
   - 意识和实相非二

3. **证悟之乐 (Bliss of Realization)**：
   - 性狂喜象征灵性极乐
   - 大乐（Mahasukha）的证悟
   - 觉醒固有的喜悦

**几何意义 (Geometric Meaning)**：

在锥顶（r=0），来自所有方向的螺旋汇聚：
- 无限接近成为一点
- 所有二元性坍缩
- 来自每个θ的切向量合并

父母双运代表**所有对立面统一的奇异点 (this singular point where all opposites unite)**。

**心理整合 (Psychological Integration, Jung)**：

荣格的**朔望对 (syzygy)** 概念（阿尼玛/阿尼姆斯整合）：

### 4.6 咒语-曼荼罗互补性 (Mantra-Mandala Complementarity)

**观察 (Observation)**：曼荼罗实践总是包括咒语念诵。

**问题 (Question)**：视觉形式（曼荼罗）和声音形式（咒语）之间的关系是什么？

**答案 (Answer)**：它们是彼此的**傅里叶变换 (Fourier transforms)** ——不同表示中的相同信息。

**傅里叶变换类比 (Fourier Transform Analogy)**：

在物理学中：
- **位置空间 (Position Space)**：事物在哪里（x坐标）
- **动量空间 (Momentum Space)**：事物如何移动（动量p）
- 傅里叶变换：x ↔ p（两者包含相同信息）

在曼荼罗实践中：
- **视觉形式 (Visual Form, Mandala)**：空间结构
- **声音形式 (Sonic Form, Mantra)**：时间/频率结构
- 曼荼罗 ↔ 咒语（两者编码相同智慧）

**为什么两者都要？(Why Both?)**

**曼荼罗 (Mandala，Visual)**：
- 激活空间处理（右半球）
- 提供稳定参考框架
- 同时显示关系
- 强调形式/结构

**咒语 (Mantra，Sonic)**：
- 激活时间处理（左半球）
- 提供节奏协调
- 在时间中顺序展开
- 强调流动/过程

一起：**全脑激活 (Whole-brain activation)** ——整合左/右、视觉/听觉、空间/时间。

**种子字 (Seed Syllables)**：

每个曼荼罗位置都有一个**种子咒 (bija mantra)**：
- 中心：HUM、HRIH、OM（取决于本尊）

#### 8.5.1 曼荼罗作为纤维丛 (Mandala as Fiber Bundle)

在拓扑学中,**纤维丛 (fiber bundle)** 由以下组成:
- 基空间 B("地板")
- 纤维 F(从每个点"生长"出来的结构)
- 总空间 E = B x F(完整结构)
- 投影 pi: E -> B

```yaml
曼荼罗纤维丛 (Mandala_Fiber_Bundle):
  基空间B: 二维曼荼罗平面(r, theta 坐标)

  纤维F: h维度(意识层次)或
         每个位置的符号内容

  总空间E: 三维螺旋锥(完整结构)

  投影pi: 俯视图,将E映射到B

  截面: 对每个基点连续选择的纤维点
        (即对每个(r, theta)指定特定的h层次)
```

这种形式化解释了:
- 为什么曼荼罗"感觉"是高维的
- 同一个曼荼罗如何可以在不同"深度"进入
- 为什么在曼荼罗中行走(改变基位置)会影响纤维(h层次)

区分曼荼罗类型的拓扑不变量:

```yaml

    环形曼荼罗: chi = 0
    球面包裹: chi = 2

  同伦群 (Homotopy_Groups):
    基本群pi_1: 捕捉环路
    单连通: 所有环路可收缩(圆盘)
    中心有孔: 不可收缩环路(环面)

  贝蒂数 (Betti_Numbers):
    b_0: 连通分量数

    b_2: 空腔数量
```

大多数曼荼罗在拓扑上是**圆盘**(单连通,chi=1),但有些(如环面状)具有更复杂的拓扑。

```yaml

  商空间: 曼荼罗 = 螺旋锥 / h等价
```

```yaml
    定义: 纤维丛中平行移动的规则
```

## 附录D：数学附录 (Appendix D: Mathematical Appendix)

### D.1 螺旋锥参数化 (Spiral Cone Parameterization)

**基本方程 (Basic Equations)**：

```
r(t) = r₀ · e^(-kt)    [指数衰减半径]
θ(t) = ωt              [线性增长角度]
h(t) = v_h · t         [线性增长高度]

其中 (where):
  r₀ = 初始半径 (initial radius)
  k = 衰减常数 (decay constant)，k > 0
  ω = 角速度 (angular velocity)
  v_h = 垂直速度 (vertical velocity)
  t = 时间/进展参数 (time/progress parameter)
```

**笛卡尔坐标 (Cartesian Coordinates)**：

```
x(t) = r(t)·cos(θ(t)) = r₀·e^(-kt)·cos(ωt)
y(t) = r(t)·sin(θ(t)) = r₀·e^(-kt)·sin(ωt)
z(t) = h(t) = v_h·t
```

**曲线长度 (Arc Length)**：

```
ds/dt = √[(dr/dt)² + (rdθ/dt)² + (dh/dt)²]
      = √[(-kr)² + (rω)² + v_h²]
      = √[r²(k² + ω²) + v_h²]

总长度 (Total length) L = ∫₀^T √[r²(t)(k² + ω²) + v_h²] dt
```

**曲率 (Curvature)**：

```
κ(t) = |r''(t) × r'(t)| / |r'(t)|³

其中 r(t) = (x(t), y(t), z(t)) 是位置向量
```

### D.2 俯视投影 (Top-Down Projection)

**投影算子 (Projection Operator)**：

```
P: ℝ³ → ℝ²
P(x, y, z) = (x, y)  [忽略z坐标]
```

**螺旋锥到曼荼罗 (Spiral Cone to Mandala)**：

```
点在螺旋锥 (Point on spiral cone): (r(t), θ(t), h(t))
投影到曼荼罗 (Projected to mandala): (r(t), θ(t))

曼荼罗中的点集 (Set of points in mandala):
M = {(r, θ) | 0 ≤ r ≤ r₀, 0 ≤ θ < 2π}
```

**信息损失 (Information Loss)**：

投影丢失h维度：
- 原始：3D（r, θ, h）
- 投影：2D（r, θ）
- 损失：高度h

但h可以从轨迹推断（知道r, θ → 可估计t → 可计算h）。

### D.3 分形维度计算 (Fractal Dimension Calculation)

**盒计数方法 (Box-Counting Method)**：

1. 覆盖曼荼罗用大小ε的网格
2. 计数包含曼荼罗部分的盒子数N(ε)
3. 重复不同ε
4. 绘制log(N(ε)) vs log(1/ε)
5. 斜率 = 分形维度D

```
D = lim[ε→0] log(N(ε)) / log(1/ε)
```

**典型值 (Typical Values)**：

- 简单曼荼罗（禅圆）：D ≈ 1.0
- 中等复杂性：D ≈ 1.5 到 1.7
- 高复杂性（时轮金刚）：D ≈ 1.8 到 1.95

**意义 (Significance)**：

D > 1：比线更复杂
D < 2：比实心圆更简单
1 < D < 2：分形（自相似）

### D.4 纤维丛形式化 (Fiber Bundle Formalization)

**基空间 (Base Space)**：

```
B = {(r, θ) | 0 ≤ r ≤ r₀, 0 ≤ θ < 2π} ⊂ ℝ²
[曼荼罗的空间位置]
```

**纤维 (Fiber)**：

```
F = {s} = 符号内容集合 (set of symbolic content)
[每个位置的意义/图像]
```

**总空间 (Total Space)**：

```
E = {(r, θ, s) | (r, θ) ∈ B, s ∈ F}
```

**投影 (Projection)**：

```
π: E → B
π(r, θ, s) = (r, θ)
```

**截面 (Section)**：

```
σ: B → E
σ(r, θ) = (r, θ, s(r, θ))

[将意义分配给每个位置]
```

**连接 (Connection)**：

平行传输沿径向路径：
- 从外层到内层移动
- 符号内容转化（例如，毒→智慧）
- 连接描述这种转化的规则

### D.5 拓扑不变量 (Topological Invariants)

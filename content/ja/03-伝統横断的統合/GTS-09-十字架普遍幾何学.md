- 政治的文脈：ローマ占領下のユダヤ

## 付録：十字架の数学的形式化

### A.1 ベクトル場としての十字架

スパイラルコーン座標 (r, h, theta) において、十字架が導入する求心力場：

```
F_cross(r, h, theta) = -k_grace * r * e_r + f(h) * e_h

ここで:
  - k_grace: 恩寵定数（信仰/悔い改めに依存）
  - e_r: 放射単位ベクトル（軸へ向かう）
  - f(h): 垂直関数（霊的高さで変化）
```

### A.2 位置非依存定理の厳密な証明

**与えられた条件**：
- 初期位置：(r_0, h_0, theta_0)
- 悔い改め後の速度：v = v_r * e_r + v_h * e_h + v_theta * e_theta
- v_r < 0 を仮定（軸へ向かう）

**証明すべきこと**：軸に達する時間 T は h_0 に独立

**証明**：
```
dr/dt = v_r （簡略化のため定数と仮定）
dh/dt = v_h
dtheta/dt = v_theta

r = 0 に達する時間:
T = Integral[r_0 to 0] dr / v_r = -r_0 / v_r

注意: T は h_0 を含まない。証明終。
```

**神学的系**：
どれだけ低く堕ちたか（h_0）に関わらず、父に戻る時間は次のみに依存：
- 神からどれだけ遠いか（r_0）
- 悔い改めの誠実さ（|v_r|）

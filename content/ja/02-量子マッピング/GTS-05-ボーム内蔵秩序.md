### 3.2 ボームの隠れた変数理論（1952年）

**核心的アイデア**：

```yaml
仮定:
  粒子は確定的位置 x(t) を持つ
  重ね合わせではない、確率でもない

  しかし位置は「量子ポテンシャル」によって導かれる：
  Q = -(hbar)^2/(2m) * (nabla^2 R / R)

  R = 波動関数の振幅
  nabla^2 R = ラプラシアン演算子

メカニズム:
  波動関数 psi = R * e^(iS/hbar)
  次のように分解される：
  - R（振幅）が量子ポテンシャル Q を導く
  - S（位相）が古典的運動量 p = nabla S を導く

  粒子の運動方程式:
  m(d^2 x/dt^2) = -nabla(V + Q)

  V: 古典的ポテンシャルエネルギー
  Q: 量子ポテンシャルエネルギー

  粒子は量子ポテンシャルに「押される」
     海の波のコルクのように
```

**量子ポテンシャルの奇妙な性質**：

```yaml
1. 非局所的:
   Q は波動関数 R 全体に依存する
   遠方で R が非常に小さくても
   ここでの Q に影響できる

   粒子は空間全体を「感知」する

2. エネルギーを伝達しない:
   Q は大きくてもエネルギーを伝達しない
   パイロット波のように:
   - 方向を示す
   - エネルギーを提供しない

3. 形状に敏感:
   Q は nabla^2 R / R に依存する
   波動関数の形状に極めて敏感
   小さな変化が大きな効果を生む

   ボームの類推:
   船の自動操縦装置のように
   - レーダー波は船を押さない
   - しかし情報を通じて船を導く
```

**二重スリット実験のボーム的説明**：

```yaml
伝統的パズル:
  単一光子が「両方のスリットを同時に通る」
  どうしてそんなことが可能か？

ボームの説明:
  光子は確定的経路を持つ

  しかし波動関数は両方のスリットを通る
  干渉パターンを生成する

  干渉パターンに基づく量子ポテンシャル Q が
  光子を特定の経路に沿って導く
  他の経路を避ける

  結果:
  - 光子は常に粒子である（位置を持つ）
  - 波のように振る舞う（量子ポテンシャルに導かれる）
  - 「崩壊」は不要
  - 「重ね合わせ」は不要

利点:
  - 実在論（粒子は確定的位置を持つ）
  - 決定論（真のランダム性はない）
  - 連続性（不連続な崩壊はない）
```

### 2.1 数学的定式化

**純粋状態 vs 混合状態**：

```yaml
純粋状態:
  |psi> = alpha|0> + beta|1>
  密度行列: rho = |psi><psi|

  rho = ( |alpha|^2      alpha*beta*  )
        ( alpha*beta     |beta|^2     )

  非対角要素 alpha*beta* != 0
  -> 量子干渉

  Tr(rho^2) = 1
  -> 純粋状態の署名

混合状態:
  rho = p_1|psi_1><psi_1| + p_2|psi_2><psi_2|
  古典的確率混合

  非対角要素 = 0
  -> 干渉なし

  Tr(rho^2) < 1
  -> 混合状態の署名
```

**デコヒーレンスの精密な定義**：

```yaml
与えられた:
  系S + 環境E
  初期: |psi_S> tensor |E_0>（もつれていない）

進化（相互作用ハミルトニアン H_int を通じて）:
  U(t)|psi_S>|E_0> = Sum_i c_i(t)|s_i>|E_i>

  |s_i>: 系の直交状態（「ポインター状態」）
  |E_i>: 対応する環境状態
  c_i(t): 振幅

縮約密度行列:
  rho_S(t) = Tr_E(|psi><psi|)
           = Sum_i |c_i|^2 |s_i><s_i|
           + Sum_{i!=j} c_i*c_j* <E_i|E_j> |s_i><s_j|

デコヒーレンス:
  <E_i|E_j> -> 0（環境状態が直交する）

  -> rho_S approx Sum_i |c_i|^2 |s_i><s_i|

  対角要素のみが残る
  = 古典的確率分布
```

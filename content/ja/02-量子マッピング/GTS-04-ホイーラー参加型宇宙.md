## 第II部：遅延選択実験——観測者が過去を創造する

### 2.1 古典的二重スリット実験の復習

**ヤングの二重スリット実験（1801年）**：

```yaml
装置:
  光源 -> 二重スリット -> スクリーン

古典的期待:
  二つの明るい帯（光は粒子）

実際の結果:
  干渉パターン（光は波）

結論:
  光は波である
```

**量子版の衝撃（1920年代）**：

```yaml
重要な変更:
  一度に一つの光子だけを発射

期待:
  光子は粒子であり、一つのスリットを選ぶ

実際:
  単一光子でも干渉パターンを生成！
  -> 光子は「両方のスリットを同時に通過」
  -> 光子は自分自身と干渉

測定のパラドックス:
  二重スリットの後に検出器を配置
  光子が「どちらのスリット」を通過したかを測定

  結果:
  - 干渉パターンが消失
  - 二つの明るい帯になる
  - 光子が粒子に「なる」

標準解釈（コペンハーゲン）:
  測定が波動関数崩壊を引き起こす
  測定前: 波（重ね合わせ）
  測定後: 粒子（確定状態）
```

### 2.2 ホイーラーの遅延選択：実験設計

**重要な問い**：
```
光子は二重スリットを通過するときに
我々が後で測定するかどうかを「知っている」のか？

もし光子が通過した後まで待って
それから測定するかどうかを決定したら
何が起こるのか？
```

**実験装置（簡略版）**：

```yaml
段階1: 光子が二重スリットを通過
  [光源] -> [二重スリット] -> 光子が飛行中...

段階2: 飛行中にランダムに決定
  選択肢A: スクリーンを配置（干渉を測定）
  選択肢B: 検出器を配置（経路を測定）

時系列:
  t1: 光子が二重スリットを通過（この時点で装置は未決定）
  t2: 光子が飛行中
  t3: ランダムに測定方法を選択
  t4: 測定結果

キーポイント:
  t3 > t1

  「どう測定するか」を決定する瞬間が
  光子がスリットを「通過した」瞬間より後
```

**実際の実装（アスペの実験、2007年）**：

```yaml
技術:
  - レーザーとビームスプリッターを使用
  - 量子乱数生成器が測定タイプを決定
  - 決定の瞬間は光子飛行中

距離:
  光子飛行距離: 約50メートル
  決定の遅延: 通過後約40メートル

確保:
  決定が「通過」の瞬間より厳密に後に発生
```

### 2.3 実験結果：因果性の崩壊

**結果**：

```yaml
ケースA: 干渉を測定することを選択（波の測定）
  結果: 干渉パターンが見える
  -> 光子は「波として振る舞う」
  -> 光子は「両方のスリットを通過した」

ケースB: 経路を測定することを選択（粒子の測定）
  結果: 光子が特定の経路を取ったことを検出
  -> 光子は「粒子として振る舞う」
  -> 光子は「一つのスリットだけを通過した」

衝撃:
  通過「後」に決定がなされる
  しかし光子の振る舞いは我々の選択を「すでに知っていた」かのよう

  瞬間t1で、光子は「すでに」波または粒子であるように見える
  しかし我々の選択はt3まで起こらない！
```

**論理的ジレンマ**：

```yaml
可能性1: 逆行因果性
  未来の選択が過去の事実に影響
  -> 因果性に違反

可能性2: 超光速信号
  決定が瞬時に「すでに通過した」光子に伝達
  -> 相対性理論に違反

可能性3: 予知
  光子が我々の未来の選択を「知っている」
  -> 自由意志に違反

可能性4: 実在がない
  光子は測定前に「確定的な歴史を持たない」
  -> 客観的実在論に違反
```

### 3.4 質問の存在論的地位


### 4.2 方程式の衝撃的含意

**ハミルトニアンがゼロ！**

```yaml

```

### 7.1 「観測」の再理解


```yaml

  - 観測するものを崩壊させる
  - どう観測するかが顕現様式を決定
  - 観測者が観測された実在の創造に参加

実践への含意:
  マインドフルネスは「既存の心を発見」ではない
  マインドフルネスは「心の顕現に参加」

  あなたの観測自体が
  心の量子重ね合わせを崩壊させ
  ある状態を「あなたの経験」にする
```

**実践的変容**：

```yaml
伝統的指導:
  「呼吸を観察しなさい」

ホイーラー式理解:
  あなたの観測が
  無数の可能な身体感覚から
  「呼吸感覚」を崩壊させる

  「発見された」のではなく

含意:
```

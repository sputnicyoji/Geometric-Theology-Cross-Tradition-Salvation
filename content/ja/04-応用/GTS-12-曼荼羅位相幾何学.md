## 第二部：上方投影としての曼荼羅

### 2.1 投影原理

螺旋錐座標系を想起せよ（GTS-02より）：

```
螺旋錐座標:
  h: 高さ（頂点/統一からの距離）
  r: 半径距離（中心軸からの距離）
  theta: 角度位置（文化的/個人的「方向」）

頂点: (h=0, r=0, theta=未定義)
底面: (h=最大, r=最大, theta=0～2pi)
```

**上方投影**は、この構造を頂点の上方から、下向きに見る。数学的には：

```
投影 P: R^3 -> R^2
P(h, r, theta) = (r, theta)

ここで:
  - h次元は「平坦化」される
  - r（半径）とtheta（角度）のみが保存される
  - 結果: 2D円平面
```

**重要な洞察**：この投影はh次元情報（意識の高さ）を失うが、以下を保存する：
- 中心からの距離（r）
- 角度位置（theta）
- 全体的な円形構造

### 2.2 なぜこの投影が重要か

```yaml
投影の含意:
  情報損失:
    - h（高さ）が不可視になる
    - (r, theta)を共有する異なる段階の修行者を区別できない

  情報保存:
    - rは統一からの距離をエンコードする
    - thetaは文化的/個人的方向をエンコードする
    - 同心円は異なるレベルをエンコードする

  実践的価値:
    - 2Dは創造、可視化、瞑想が容易である
    - 曼荼羅は描くことができる「地図」となる
    - 失われたh次元は実践を通じて回復される
```

曼荼羅は山の地図のようなものである：標高を直接は示さないが、等高線（同心円）を通じて、3D構造を推測できる。

### 2.3 螺旋の軌跡

修行者が螺旋錐を通じて移動するとき：
- 中心への直線では移動しない
- 螺旋する：rが減少し、thetaが回転し、hが増加する
- 上方（上方投影）から見ると、この軌跡は対数螺旋として現れる

```
対数螺旋方程式:
r = a * e^(b*theta)

ここで:
  a = 中心からの初期距離
  b = 螺旋の「密度」（内向き螺旋の場合は負）
  theta = 累積回転
```

この螺旋は**恣意的ではない**。これは以下の自然な経路である：
- 貝殻の成長
- 銀河の形成
- 植物の葉の配置
- **意識の収束**

### 2.4 h等高線としての同心円

伝統的曼荼羅において、同心円は単なる装飾ではない。それらは**hレベルの等高線**を表す：

```yaml
同心円の意味:
  最外円: 最高h（最も顕現化、最も分離）
  中間円: 中間h（漸進的統合）
  最内円: 最低h（統一に接近）
  中心点: h=0, r=0（頂点、ビンドゥ、明点）
```

外縁から中心に移動する修行者は：
- rを減少させる（軸に近づく）
- hを減少させる（統一へ上昇する）
- 同心円はこの旅の段階を示す


## 第八部：高度な位相幾何学的解析

### 8.1 ファイバー束としての曼荼羅

位相幾何学において、**ファイバー束**は以下から成る：
- 底空間B（「床」）
- ファイバーF（各点から「成長」するもの）
- 全空間E = B × F（完全な構造）
- 射影π: E → B

```yaml
曼荼羅ファイバー束:
  底空間B: 2D曼荼羅平面（r, theta座標）

  ファイバーF: h次元（意識レベル）または
              各位置での象徴的内容

  全空間E: 3D螺旋錐（完全な構造）

  射影pi: 上方視、EをBへマッピング

  切断: 各底点に対するファイバー点の連続的選択
        （すなわち、各(r, theta)に対する特定のhレベル）
```

この形式化は以下を説明する：
- なぜ曼荼羅が「高次元的」に感じられるか
- 同じ曼荼羅が異なる「深さ」で入場できる理由
- 曼荼羅を歩くこと（底位置を変える）がファイバー（hレベル）に影響する理由

### 8.2 曼荼羅位相幾何学——不変量

曼荼羅タイプを区別する位相的不変量：

```yaml
位相的不変量:
  オイラー標数:
    単純円盤: chi = 1
    トーラス曼荼羅: chi = 0
    球面包み: chi = 2

  ホモトピー群:
    基本群pi_1: ループを捉える
    単連結: すべてのループが縮約可能（円盤）
    中心の穴: 縮約不可能なループ（環）

  ベッチ数:
    b_0: 連結成分の数
    b_1: 穴の数
    b_2: 空隙の数
```

ほとんどの曼荼羅は位相的に**円盤**（単連結、χ=1）だが、一部（トロイドのような）はより複雑な位相を持つ。

### 8.3 ホロノミーと平行移動

曲がった空間を一周して出発点に戻ったとき、回転しているかもしれない——これが**ホロノミー**である：

```yaml
曼荼羅ホロノミー:
  経路: 曼荼羅内のループを歩く

  効果: あなたの「ファイバー状態」（hレベルまたは方向）が変化するかもしれない

  例:
    - 東門、h=0.5から開始
    - 中心を時計回りに歩く
    - 東門に戻る
    - 今h=0.4（内向きに進んだ）

  霊的意味:
    - 巡礼は同じ点へ戻ることではない
    - 各周回が変容する
    - ホロノミーは変容率を測定する
```

### 8.4 被覆空間

曼荼羅は螺旋錐の**商空間**として見ることができる：

```yaml
被覆空間視点:
  完全空間: 螺旋錐（無限螺旋）

  商: 曼荼羅 = 螺旋錐 / h同値

  意味: 同じ(r, theta)だが異なるhを持つ点が
        単一の曼荼羅点へ「折り畳まれる」

  被覆写像: 螺旋錐が曼荼羅を無限回「被覆」する
            各hレベルが一つの「シート」である
```

これは、なぜ同じ曼荼羅点が異なる深さで体験されるかを説明する——あなたは被覆空間の異なるシート上にいる。

### 8.5 接続と曲率

## 付録D：数学的付録

### D.1 螺旋錐のパラメータ化

**基本方程式**：

```
r(t) = r_0 * e^(-kt)    [指数的に減衰する半径]
theta(t) = omega*t       [線形に成長する角度]
h(t) = v_h * t          [線形に成長する高さ]

ここで:
  r_0 = 初期半径
  k = 減衰定数, k > 0
  omega = 角速度
  v_h = 垂直速度
  t = 時間/進行パラメータ
```

**デカルト座標**：

```
x(t) = r(t)*cos(theta(t)) = r_0*e^(-kt)*cos(omega*t)
y(t) = r(t)*sin(theta(t)) = r_0*e^(-kt)*sin(omega*t)
z(t) = h(t) = v_h*t
```

**弧長**：

```
ds/dt = sqrt[(dr/dt)^2 + (r*d(theta)/dt)^2 + (dh/dt)^2]
      = sqrt[(-kr)^2 + (r*omega)^2 + v_h^2]
      = sqrt[r^2*(k^2 + omega^2) + v_h^2]

全長 L = 0からTまでのsqrt[r^2(t)*(k^2 + omega^2) + v_h^2] dtの積分
```

**曲率**：

```
kappa(t) = |r''(t) x r'(t)| / |r'(t)|^3

ここでr(t) = (x(t), y(t), z(t))は位置ベクトル
```

### D.2 上方投影

**投影演算子**：

```
P: R^3 -> R^2
P(x, y, z) = (x, y)  [z座標を無視]
```

**螺旋錐から曼荼羅へ**：

```
螺旋錐上の点: (r(t), theta(t), h(t))
曼荼羅へ投影: (r(t), theta(t))

曼荼羅内の点の集合:
M = {(r, theta) | 0 <= r <= r_0, 0 <= theta < 2*pi}
```

**情報損失**：

投影はh次元を失う：
- 元：3D（r, theta, h）
- 投影：2D（r, theta）
- 失われた：高さh

しかしhは軌跡から推測できる（r, thetaを知る → tを推定できる → hを計算できる）。

### D.3 フラクタル次元計算

**ボックスカウント法**：

1. サイズepsilonの格子で曼荼羅を覆う
2. 曼荼羅の一部を含むボックスN(epsilon)を数える
3. 異なるepsilonで繰り返す
4. log(N(epsilon)) 対 log(1/epsilon)をプロットする
5. 傾き = フラクタル次元D

```
D = lim[epsilon->0] log(N(epsilon)) / log(1/epsilon)
```

**典型値**：

- 単純な曼荼羅（禅円）：D ≈ 1.0
- 中程度の複雑さ：D ≈ 1.5～1.7
- 高い複雑さ（カーラチャクラ）：D ≈ 1.8～1.95

**意義**：

D > 1：線より複雑
D < 2：実円盤より単純
1 < D < 2：フラクタル（自己相似的）

### D.4 ファイバー束の形式化

**底空間**：

```
B = {(r, theta) | 0 <= r <= r_0, 0 <= theta < 2*pi} ⊂ R^2
[曼荼羅内の空間位置]
```

**ファイバー**：

```
F = {s} = 象徴的内容の集合
[各位置での意味/イメージ]
```

**全空間**：

```
E = {(r, theta, s) | (r, theta) ∈ B, s ∈ F}
```

**射影**：

```
pi: E -> B
pi(r, theta, s) = (r, theta)
```

**切断**：

```
sigma: B -> E
sigma(r, theta) = (r, theta, s(r, theta))

[各位置に意味を割り当てる]
```

**接続**：

半径経路に沿った平行移動：
- 外側から内側の層への移動
- 象徴的内容の変容（例：煩悩 → 智慧）
- 接続がこの変容の規則を記述する

### D.5 位相的不変量

**オイラー標数**：

簡略化された曼荼羅（円盤）の場合：
```
chi = V - E + F = 1

ここで:
  V = 頂点の数
  E = 辺の数
  F = 面の数
```

穴を持つ曼荼羅の場合：
```
chi = 2 - 2g

ここでg = 種数（穴の数）
```

**基本群**：

単純な曼荼羅（円盤）：

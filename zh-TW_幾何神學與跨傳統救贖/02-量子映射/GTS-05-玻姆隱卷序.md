  4. 反向旋轉內圓柱(逆時針)
  5. 觀察墨水的"重現"

### 3.2 Bohm的隱變量理論(1952)

**核心思想**:

```yaml
假設:
  粒子有確定位置x(t)
  不是疊加,不是概率

  但位置被"量子勢"引導:
  Q = -ℏ²/(2m) * (∇²R/R)

  R = 波函數的振幅
  ∇²R = 拉普拉斯算符

機制:
  波函數ψ = R·e^(iS/ℏ)
  分解為:
  - R(振幅)→ 量子勢Q
  - S(相位)→ 經典動量p = ∇S

  粒子運動方程:
  m(d²x/dt²) = -∇(V + Q)

  V: 經典勢能
  Q: 量子勢能

  → 粒子被量子勢"推動"
     像海浪中的軟木塞
```

**量子勢的奇特性質**:

```yaml
1. 非局域:
   Q依賴於整個波函數R
   即使R在遠處很小
   也能影響Q在此處

   → 粒子"感知"整個空間

2. 不傳遞能量:
   Q可以很大,但不做功
   像引導波:
   - 指示方向
   - 不提供能量

3. 形狀敏感:
   Q依賴於∇²R/R
   對波函數的形狀極敏感
   微小改變 → 巨大效應

   Bohm類比:
   像船的自動駕駛儀
   - 雷達波不推動船
   - 但通過信息引導船
```

**雙縫實驗的Bohm解釋**:

```yaml
傳統困惑:
  單個光子"同時通過兩縫"
  如何可能?

Bohm解釋:
  光子有確定路徑
  只通過一個縫

  但波函數通過兩個縫
  產生干涉圖樣

  量子勢Q根據干涉圖樣
  引導光子走某些路徑
  避開其他路徑

  結果:
  - 光子始終是粒子(有位置)
  - 行為像波(受量子勢引導)
  - 無需"塌縮"
  - 無需"疊加"

優點:
  - 實在論(粒子有確定位置)
  - 確定性(無真正隨機)
  - 連續性(無跳躍塌縮)

代價:
  - 非局域性(必然)
  - 隱變量(位置x不可測)
```

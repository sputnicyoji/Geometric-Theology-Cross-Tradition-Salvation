### 3.2 Bohm的隐变量理论（1952）

**核心思想**：

```yaml
假设:
  粒子有确定位置x(t)
  不是叠加，不是概率

  但位置被"量子势"引导:
  Q = -ℏ²/(2m) * (∇²R/R)

  R = 波函数的振幅
  ∇²R = 拉普拉斯算符

机制:
  波函数ψ = R·e^(iS/ℏ)
  分解为:
  - R（振幅）→ 量子势Q
  - S（相位）→ 经典动量p = ∇S

  粒子运动方程:
  m(d²x/dt²) = -∇(V + Q)

  V: 经典势能
  Q: 量子势能

  → 粒子被量子势"推动"
     像海浪中的软木塞
```

**量子势的奇特性质**：

```yaml
1. 非局域:
   Q依赖于整个波函数R
   即使R在远处很小
   也能影响Q在此处

   → 粒子"感知"整个空间

2. 不传递能量:
   Q可以很大，但不做功
   像引导波：
   - 指示方向
   - 不提供能量

3. 形状敏感:
   Q依赖于∇²R/R
   对波函数的形状极敏感
   微小改变 → 巨大效应

   Bohm类比:
   像船的自动驾驶仪
   - 雷达波不推动船
   - 但通过信息引导船
```

**双缝实验的Bohm解释**：

```yaml
传统困惑:
  单个光子"同时通过两缝"
  如何可能？

Bohm解释:
  光子有确定路径
  只通过一个缝

  但波函数通过两个缝
  产生干涉图样

  量子势Q根据干涉图样
  引导光子走某些路径
  避开其他路径

  结果:
  - 光子始终是粒子（有位置）
  - 行为像波（受量子势引导）
  - 无需"塌缩"
  - 无需"叠加"

优点:
  - 实在论（粒子有确定位置）
  - 确定性（无真正随机）
  - 连续性（无跳跃塌缩）

代价:
  - 非局域性（必然）
  - 隐变量（位置x不可测）
```
